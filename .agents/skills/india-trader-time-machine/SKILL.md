# India Trader Time Machine

When locally configured, FYERS historical candles are an optional NSE cash-equity fallback between Upstox and Yahoo for the 60-day replay. The FYERS adapter is offline-tested but has not been live account-tested.

Run `python -m india_trader time-machine run --write` after `$india-trader-exit` writes `trader/plan.json`. It reads the saved long cash-equity entry, stop, target, opening-range settings, and flat-by time. `--symbol RELIANCE --date YYYY-MM-DD --entry 100 --stop 99 --target 102 --entry-time 09:40` makes an explicitly hypothetical plan when there is no saved file. The original's `--side sell` is also supported for **manual paper research** with `target < entry < stop`; the current India exit planner and paper budget do not create or size short plans. `--offline FILE` reads a saved Yahoo 60-day five-minute chart JSON or `.json.gz` for a reproducible run; otherwise the program tries chunked historical candles from a configured read-only Upstox source, then unofficial Yahoo fallback. `--now ISO_TIME` pins the cutoff; it does not establish a current signal. `--replays`, `--seed` (default 19), `--window` (default two bars), and `--until` adjust the run. `python -m india_trader time-machine chart --from trader/timemachine.json` prints the saved ASCII fan chart and 24-bin exit-price histogram.

The scenario pool uses only full 72-bar sessions strictly before the plan date in the conservative 09:15–15:15 IST window. At least 20 full prior sessions and the plan's completed entry bar are required. Missing or partial sessions and one-minute charts fail closed or are excluded. Each path resamples the stock's historical five-minute OHLC ratios at the same time of day, plus or minus the requested window, and checks the stop before the target. A bar touching both counts as stop. The run reports target-first, stop-first, neither, green, exit-time median and 5–95% price range, average R, 2,000-path percentile bands, 160 sample paths, and the seed. These are descriptive scenario fractions, not calibrated probabilities or predictions.

The separate historical replay runs the same opening-range minutes and target R on each full past session. Opening-range midpoint and long-side low or short-side high stop rules replay directly; `auto` infers these from the plan-day opening range when possible. ATR, fixed-price and percentage stops use the plan's **percentage risk** as a historical proxy and the output names that proxy. The local replay handles an opening gap through the stop at that bar's open. Its tick size is taken from the plan as an assumption, never independently verified. Report the actual historical triggered/target/stop/neither counts and average R separately from synthetic results. For a non-ORB setup, the historical rule replay is unavailable and says so.

Use the printed verdict and notes as written. A verdict compares target share **among boundary hits** with `1 / (1 + target R)`; it is not a profitability claim. Explain if the historical result and synthetic result disagree. Check `$india-trader-news` before interpreting a current plan; hand off only a **buy** plan to the paper budget if the user wants paper sizing. The Time Machine never sizes a position or places an order. Upstox account behavior has not been live tested; Yahoo bars are unofficial, may have missing volume or corporate-action effects, and are not reconciled to NSE. Results omit fees, taxes, spread, slippage, market impact, and out-of-sample validation. Do not call a hypothetical or historical result a live signal.
